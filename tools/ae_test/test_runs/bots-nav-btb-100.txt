# BOT NAV ON THE BIG TEAM BATTLE MAPS: each map carries a nav file of vehicle routes (lanes base to base, base exits,
# crossings; scorpion lines where a tank fits) and keepouts where a lane must stay off. Each rock and tree's footprint is
# measured at the map load and drivers steer round it. A driver with a far goal follows the routes, the usual search after
# their end; on Danger Canyon the bases are joined for vehicles only by the canyon, so the routes are taken however long.
# Each test seats the player in a warthog's gun seat with a teammate bot at the wheel: watch the line it drives. Log at
# the load: "bot nav: <map> (built in): N routes (N points), N keepouts"; with bot events "bot nav: bot N on route
# <name>". Cliffhanger is a Workshop map: it needs the map from the Workshop.
list bots-nav-btb-100
revision 6
title BOT NAV: THE BIG TEAM BATTLE MAPS

group dangercanyon
map dangercanyon@mcc
gametype AE BTB CTF
set bots.count 12
set debug.bot_events true

test drive-dangercanyon
title Danger Canyon: the rocket warthog past the boulder
setup goto -17.0 -2.8 -3.5 facing 90
setup seat driver mate
setup seat gunner
check You ride the rocket warthog's gun seat
check It leaves the row clear of the boulder and pine
check It takes the west lane, west of the big boulder
expect 1 log bot nav: dangercanyon (built in)
expect 3 log on route west_lane

test drive-dangercanyon-far
title Danger Canyon: on through the pit to the red base
setup goto -7.5 -3.6 -3.5 facing 180
setup spawn mp_warthog here
setup seat driver mate
setup seat gunner
check You ride the warthog's gun seat
check It goes round the platform's south arm, out west
check Pit, then up the east lane clear of the rocks
