# 0.9.4 TAB MENU PAGES: the TAB / START menu has two new pages before QUIT, CREDITS and NETWORK STATUS. CREDITS scrolls a text
# of headed sections (credits.txt beside the game); NETWORK STATUS lists what the game already knows (the master server, the
# servers listed, your port, the versions) and says "unknown" for the rest. B, Esc or a right click on a page goes back to the
# TAB menu. Every test opens on its scene from its setup lines: `menu tab` opens the TAB menu, `menu credits` the credits,
# `menu network` the live status, `menu network reached|unreached|unknown` the status with made-up facts (the real master and
# port cannot be staged: nothing here asks the network).
list tab-pages-094
revision 1
title TAB MENU PAGES

test tab-rows
title TAB menu: the two new rows
check Rows end SETTINGS, CREDITS, NETWORK STATUS, then QUIT
check QUIT is alone under the rule, below NETWORK STATUS
check Footer: pad A Select, B Back; keys the same
menus
setup menu tab
expect 1 log ae tab menu: rows: PLAYER | CONTROLLER | KEYBOARD | SETTINGS | CREDITS

test credits-pad
title CREDITS: scroll and back, pad

menus
setup menu credits
expect 1 log ae credits: open (credits.txt
