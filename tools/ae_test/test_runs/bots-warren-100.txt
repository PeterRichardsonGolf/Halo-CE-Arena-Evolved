# 1.0 rc2 WARREN: bots on ledges and paths. The upper level's 34 degree ramps (352 of Warren's 2241 walkable surfaces
# are that steep) are not taken by the edge guard for slides into a floor's drop: a floor the map's own path data calls
# walkable is walked, up to 45 degrees. The camo platform's one way off is a walk link at its corner: a walk link is
# walked with only the map's lethal drop guarded, and the way back is open when the goal is off the platform. Edge lines
# carry the guard's probes (probe=near,far), so a stuck spot's log says what the bot saw.
