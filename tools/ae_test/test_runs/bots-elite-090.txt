# Bot level ELITE (0.9.0): HEROIC, ELITE and LEGENDARY side by side, the same map and the same two bots against you, one level a
# test. Play each test the same way (about a minute: fight the two bots, hold your own spot, do not hunt them) and compare how
# each level feels: how soon it turns and shoots when it sees you, how long it takes to hit you, how it moves, how it throws.
# Every test sets itself up (bots.count, level and sides by the bots dev command; the bot event stream is on for the logs).
# Arena maps only. Headless: run_list.py with --after 60.
list bots-elite-090
revision 2
title BOTS: ELITE BETWEEN HEROIC AND LEGENDARY

group temple
map temple
gametype AE TEAM SLY
set bots.count 2
set bots.teams against
set bots.skill heroic
set debug.bot_events true

test temple-heroic
title TEMPLE: two HEROIC bots against you
setup bots 2 against heroic
setup goto start 0
check The bots are HEROIC: reaction and aim
expect 1 log skill=heroic
check How long until the first shot that hits you
check Strafe, crouch, grenade: does it feel like HEROIC
