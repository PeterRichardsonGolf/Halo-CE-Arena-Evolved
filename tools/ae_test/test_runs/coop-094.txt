# 0.9.4 CAMPAIGN CO-OP: split-screen co-op for up to FOUR players on this PC from AE's own CAMPAIGN screen, and ONLINE co-op
# hosted from it (X on a level) and joined from the SERVER BROWSER, an invite or an address. A pad's START asks for
# a seat (its profile card, as in the lobby), its B leaves it; a lone gamepad with the keyboard joins from START too; SPLIT
# SCREEN's A does the same for the keyboard and the mouse. A level or the Play button starts it for everyone seated. CONTINUE is
# solo only (a saved game of one does not go on with more). The first seven tests are one PC (the HOST PC). The last five are TWO
# PCS: the HOST PC hosts (host-online, then play-together), the JOINING PC joins (join-browser, join-address, host-left); run them
# in this order, the host's test first, both machines on the same network with this list loaded. Every test opens on its scene:
# `menu campaign players <2-4>` seats that many players as guests on controllers 2 up, `menu campaign error` shows the co-op
# error dialog, `menu coop [players <1-4>]` hosts level 1 as a LAN game and opens the CO-OP LOBBY, `menu lan` is LAN GAMES.
