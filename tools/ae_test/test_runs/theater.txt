# THEATER, as Content Evolved has it (rc8): the main menu's THEATER row and its screen (the recordings, A watch, X delete, Y record), and the
# playback's controls over a replay (pause, skip, speed, the next player, the free camera, the lines over the screen). The screen's tests
# open on their scene from `menu theater`: `replay stage N` makes N test recordings (a header and no records: they list, and refuse to
# play), the screen's `empty` shows it as when the folder holds none, nothing real is deleted. The last group records one game with the
# bots (`replay keep` keeps it however short; a preflight's few seconds do) and plays it back with `replay play newest`, which
# skips the staged test recordings; the playback tests open on their second with `replay seek`.
list theater
revision 4
title THEATER: THE SCREEN AND THE PLAYBACK

group screen

test main-row
title MAIN MENU: THEATER is a door now
check THEATER sits under FIREFIGHT, above COMING SOON
check COMING SOON holds FORGE and FRIENDS only
check A on THEATER opens the Theater screen
menus

test list-empty
title THEATER: no recordings
check One row: NO RECORDINGS YET, with how to record
check The footer has Record: ON or OFF; no Delete prompt
check The right side explains what RECORD does
menus
setup menu theater empty
expect 1 log ae theater: open

title THEATER: three recordings
setup replay stage 3
setup menu theater
check Three rows, the newest first, each with a length

menus

expect 1 log ae theater: open
