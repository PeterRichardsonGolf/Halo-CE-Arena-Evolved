# The GRAVITY HAMMER's swing: a swing lands the hammer's blow (175, a kill) on a body it hits whose centre is within 2.8
# units, and its blast hurts and pushes what is near: 104 in a core of 1.17 units of a body's centre falling to 33 at
# 1.92, nothing farther (the blast alone never kills a full shield and health), and a push of 4.2 units a second on
# what is within 1.5 units of the blast (from the body's surface), never the one who swings (no hammer jump). The
# hammer is the START weapon on every life (debug.network_test_cache_weapon 24) beside the gametype's BR; a dummy
# stands still and never shoots. The pack is revision 4 in weapon cache serial 8: this list runs only on a build whose
# weapon cache is serial 8. The reticle is red where one swing kills: a body about 2.6 to 2.8 units away or nearer
# and within 14 degrees of the aim. Staged only: nothing here waits for something to happen.
list hammer-push-rc4
revision 4
title GRAVITY HAMMER: SWING AND BLAST

test push-near
title A dummy 1 unit ahead
setup goto 7.6 -3.2 0.6 facing 157
setup dummy 1 1
check Swing at it: one swing kills it, its body thrown
check You stay where you stood: no push up or back
check Swing at the floor at your feet: you stay put
map octagon_b
gametype AE BR TS
set bots.count 0
set debug.network_test_cache_weapon 24

test push-mid
title A dummy 1.5 units to your side
fresh
setup goto 7.6 -3.2 0.6 facing 157
setup dummy 1 1.5
setup goto 7.6 -3.2 0.6 facing 247
check Without turning, swing ahead: it is pushed, hurt
check It lives: the blast alone never kills
map octagon_b
gametype AE BR TS
set bots.count 0
set debug.network_test_cache_weapon 24

test push-far
title A dummy 3 units ahead
fresh
setup goto 7.6 -3.2 0.6 facing 157
setup dummy 1 3
check Swing toward it: no push, no damage
check Reticle not red at 3; walk in: red at about 2.7
check Swing as it turns red: one swing kills it
map octagon_b
gametype AE BR TS
set bots.count 0
set debug.network_test_cache_weapon 24
