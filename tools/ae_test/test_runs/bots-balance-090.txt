# Bot balance pass (0.9.0): every level from EASY to DEMON is evenly spaced. Each step up reacts, aims, settles and turns
# faster by the same step and sees further. NORMAL, DEMON and RECRUIT play as before; EASY and LEGENDARY a little harder;
# HEROIC easier (ELITE now plays about like the old HEROIC).
# Temple 2v2: you and one bot against two bots, all three at the level under test (the bots dev command sets count, sides
# and level). Play each group about the same way (a couple of minutes, fight normally) and say how far each level
# feels from the one before: the steps should feel about equal. Log line per bot: "skill=<level>".
# Arena map only. Headless: run_list.py with --after 60.
list bots-balance-090
revision 2
title BOTS: EVERY LEVEL EVENLY SPACED (TEMPLE 2V2)

group easy
map temple
gametype AE TEAM SLY
set bots.count 3
set bots.teams even
set bots.skill easy
set debug.bot_events true

test temple-easy
title TEMPLE 2V2: EASY bots, you and one bot against two
setup bots 3 even easy
setup goto start 0
check EASY: a bit quicker to shoot than before
expect 1 log skill=easy
check How soon a bot hits you; do you win 1v1s
check Step from the level before: same as the others
