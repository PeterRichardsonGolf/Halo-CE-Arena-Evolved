# rc2 MAP + GAMETYPE VOTE FOR A GAME YOU HOST: a game hosted from CREATE GAME with a playlist runs the same vote between games a
# dedicated server runs: three games on three maps (not the map just played) and SAME AGAIN, 20 seconds, the host's own vote in the
# same popover as the players'. `playlists demo` gives the run its own made-up playlists (4V4 ARENA in use, MAP VOTE on),
# `menu hostvote [lan] [now|join]` hosts CREATE GAME and opens the vote as if a game had just ended (now: at once; join: when a second
# person is in the lobby). The first test is ONE PC (this PC hosts, bots only). The last two are TWO PCS: the HOST PC runs
# vote-two-host first, the JOINING PC runs vote-two-join right after; both on the same network with this list loaded.
list host-vote-rc2
revision 1
title MAP VOTE FOR A GAME YOU HOST

title One PC: the host votes, the winner is next
check The vote opens: 3 games, 3 maps, SAME AGAIN, 20 s

check The winner shows NEXT GAME; UP NEXT is that game
