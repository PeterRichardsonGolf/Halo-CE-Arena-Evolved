#   score strip
# - the pause menu at 1920x1080: a value cut at the right
# - the names over heads overlapping when players stand close
list ui-look-rc1

title UI FIRST LOOK rc1: SCOREBOARD, PAUSE, NAMES

test scoreboard-split-two
