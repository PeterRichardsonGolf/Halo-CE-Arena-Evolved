When

A countdown tells the players at 60, 30, 10 and 5 seconds. Cancel stops it.

              Days 0 never ends. Only from: addresses or ranges (192.168.1.0/24), comma separated.

              Only the owner adds or removes admins.

              Who may join

                A name is no proof: anyone can take one. Admins of a moderator or above always join.

                Reserved slots

                The last slots kept for admins. When only they are left, others are told the game is full.

                Command roles

                  No changes: every command needs its own role.

                  command_access.txt in the data folder changes them, a line each (kick admin). The server reads it every 15 seconds.

                  API keys

                  A key lets a script, a bot or a panel use this server's API and RCON as one role, with no password: send it as Authorization: Bearer <key>. The server keeps only a hash of it.

                  New key

                  A name is 1 to 32 of a-z, 0-9, _ and -. A key's role is at most yours. Only from: addresses or ranges (192.168.1.0/24), comma separated.

                  This server

                  docs/dedicated_server.md is the reference of the commands, the API and the RCON.

                  Ports to open

                  Only the tunnel's port needs to reach the internet. Keep the web port on loopback, or behind a proxy that adds TLS (Caddy: reverse_proxy 127.0.0.1:8080), or reach it with ssh -L 8080:127.0.0.1:8080.

                  Where files are

                  config.toml
                  Every setting: beside the executable, or --config
                  init.txt
                  Commands run at the start (server.init_file), in the data root
                  gametypes/
                  The operator's gametypes (.toml) and saved ones (.gametype), in the data root
                  bans.txt, debug.txt
                  In paths.logs, else the data root
                  masters.txt
                  The master servers, beside the executable
                  publisher.key
                  The publisher key for the master servers, beside config.toml
                  status.json
                  The status every 2 seconds (server.status_file)
                  backups/
                  The server's copies of the files it writes, in the data root

                  Backups

                  No backups yet: the server makes one as it starts and before each write.

                  To go back to a backup: stop the server, copy the backup over its file in the data folder, then start the server. This page does not restore.
