# AE SOCIAL playlists: the offline games against bots (SOCIAL career).
# One playlist starts at a "# social: <id>" line, its "# key: value" lines follow (label, about, teams or players, party,
# kind), then its entries: map:file=<GAMETYPE>  # weight 1-5. A map named <file>@ws<item id> is a Steam Workshop map, read from
# the PC's Steam Workshop folder or download folder; <file>@smp and <file>@pro are the converted copies of the Social Map Pack
# and Pro Edition maps: the game never ships any of them, and an entry whose map is not on this PC is skipped. An entry with
# "stand-in for <map>" in its comment names the Workshop entry just above it: it plays only while that map is not here, so a
# game never has both files of one map. An entry with "fallback" in its comment
# is a stock map used when this PC has fewer than 3 of the playlist's other maps that are here (pack maps, Workshop maps, or in the
# AE COMP playlists the community competitive maps, which are plain map names). A line starting "#" with no key is a comment.
# A "# starts: br 1, evo 1" line makes each game start with one of those loadouts (br the battle rifle, evo the evo rifle, magnum
# the CE pistol, protomag the Digsite pack's starter pistol over that pistol start; the weight 1-5 is optional): picked by weight from the game's seed, where the game type has that start. A
# playlist with no starts line plays its game types as they are. "# kind: comp" playlists mirror the social ones with the
# competitive game types and mix evo and magnum starts. "# starts: none" keeps that default away; "# weapons: map" plays the maps'
# own weapons (otherwise a tournament game has AE's weapons forced on). A plain map name is a map file of this
# PC (found in the maps folder or a map share: never shipped): an entry whose map is not here is skipped, like a pack map.
