# Arena Evolved's waypoint glyphs

`overshield.png`, `camo.png` and `power_weapon.png` are Arena Evolved's own work, drawn from plain geometry by `tools/ae_waypoint_glyphs.py` (no game's picture is read or traced), and are CC0 like the code (see [LICENSE.md](../../../LICENSE.md)). The game draws them from the same tables in `port/linux/game/ae_waypoint_glyphs.c`; these files are their pictures.
